# 🚦 AI Smart Traffic Signal System

An AI-powered smart traffic management system designed to monitor traffic conditions and optimize traffic signal control using real-time traffic analysis. The system integrates a Python-based backend with an interactive web dashboard to visualize traffic conditions and support intelligent traffic management.

## 🚀 Overview

Traditional traffic signals operate using fixed timing schedules, which can lead to unnecessary congestion and inefficient traffic flow. This project aims to improve traffic management through intelligent traffic monitoring, computer vision-based analysis, and adaptive signal control.

The system provides a web-based dashboard connected to a backend API for traffic monitoring and real-time communication.

## ✨ Features

- 📊 Interactive traffic monitoring dashboard
- 🚦 Intelligent traffic signal management
- 🚗 Traffic density analysis
- 🤖 AI-based traffic processing
- ⚡ Real-time communication using WebSockets
- 🔗 FastAPI backend integration
- 📈 Visual traffic monitoring interface
- 🌐 Web-based frontend

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Smart-Traffic-System.git
```

Navigate to the project directory:

```bash
cd AI-Smart-Traffic-System
```

### 2. Setup Backend

Navigate to the backend directory:

```bash
cd backend
```

Create a virtual environment:

```bash
python3.12 -m venv venv
```

Activate the virtual environment:

**macOS/Linux:**

```bash
source venv/bin/activate
```

**Windows:**

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### 3. Start Backend Server

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Backend server:

```text
http://localhost:8000
```

API Documentation:

```text
http://localhost:8000/docs
```

### 4. Setup Frontend

Open a new terminal and navigate to the frontend directory:

```bash
cd frontend
```

Start the frontend server:

```bash
python3 -m http.server 3000
```

Open the application in your browser:

```text
http://localhost:3000
```

## 🔄 How It Works

1. The frontend dashboard provides an interface for traffic monitoring.
2. The backend server processes traffic-related requests.
3. Traffic information is analyzed using the backend processing logic.
4. The system uses traffic conditions to support signal management.
5. The frontend communicates with the backend through HTTP APIs and WebSockets.
6. Traffic-related information is displayed on the dashboard.
